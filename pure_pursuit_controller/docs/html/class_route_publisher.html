Esquema del Robot siguiendo la ruta

Clase que gestiona la selección, generación y publicación de rutas para navegación.

  • Esta clase permite seleccionar diferentes rutas predefinidas, genera una interpolación mediante Splines Cúbicos para suavizar el camino y publica tanto los objetivos (goals) como marcadores visuales para RViz.
