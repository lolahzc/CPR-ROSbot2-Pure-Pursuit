# Documentación del Proyecto: Robot Pure Pursuit con ROS2 {#mainpage}

## 1. Introducción

Bienvenido a la documentación técnica del nodo de navegación. Este proyecto implementa el algoritmo **Pure Pursuit** para que un robot móvil siga una trayectoria predefinida de forma suave y precisa.

El objetivo principal es leer una lista de *waypoints* (puntos de paso) y calcular la velocidad lineal y angular necesaria para alcanzar el siguiente punto objetivo.

## 3. Estructura del Código

El código está organizado principalmente en una clase que gestiona la lógica de control.

### Clases Principales

  • **RoutePublisher** : Esta es la clase central (el cerebro). Se encarga de:

  * Generar la ruta (Splines).

  * Publicar los marcadores visuales para RViz.

  * Calcular el control de movimiento.

### Funciones Clave

Dentro de la clase principal, las funciones más importantes que deberías revisar son:

  • generateSplineRoute() : Suavizado de la ruta.
  • computeNaturalCubicSpline() : Matemáticas del Spline.
  • publishWaypointsMarkers() : Visualización.
